# 迭代路线与版本规划

## 一期：轻量化学习工具（无大模型能力）

| 版本 | 核心内容 | 状态 | 预计时间 |
|------|----------|------|----------|
| **v1.0 MVP** | 每日抽卡、滑动交互、卡片详情、待复习/已学习、词库浏览、100词 | 已完成 | 2026-07 |
| v1.1 | 学习统计（热力图、雷达图、趋势图）、收藏夹、学习提醒推送 | 规划中 | 待定 |
| v1.2 | 词库扩展至500词、难度筛选优化、卡片分享（生成图片） | 规划中 | 待定 |
| v1.3 | 词库扩展至1000词、Web账号登录 + 云同步、智能复习算法（遗忘曲线） | 规划中 | 待定 |

### v1.0 MVP 已完成功能

- [x] 每日5张随机卡片推送
- [x] 左右滑动手势 + 红/绿遮罩动效
- [x] TTS英文发音 + 脉冲动画
- [x] 双语定义 + 应用案例展示
- [x] 待复习列表 + 已学习列表
- [x] 词库浏览（10分类 + 搜索）
- [x] 离线可用（Service Worker + localStorage）
- [x] Android APK 打包（竖屏锁定，适配 vivo/OPPO）

## 二期：接入大模型能力

| 版本 | 核心内容 | 状态 | 预计时间 |
|------|----------|------|----------|
| v2.0 | 服务端搭建、接入智谱GLM-4-Flash（主模型）+ 阿里Qwen（备用）、统一模型管理模块 | 待开发 | 待定 |
| v2.1 | 自动更新知识点（大模型 + 人工审核）、翻译功能上线、词库扩容至2000词 | 待开发 | 待定 |
| v2.2 | 自动匹配B站/抖音/GitHub视频资源、详情页"相关视频"入口、平台导流 | 待开发 | 待定 |
| v2.3 | 翻译质量优化、视频匹配精准度提升、缓存策略优化、运营后台完善 | 待开发 | 待定 |

### 二期核心能力

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 自动更新知识点 | 每周大模型自动提取前沿知识点，人工审核后入库 | P0 |
| 自动匹配视频 | 为知识点匹配B站/抖音/GitHub资源 | P0 |
| 智能翻译 | 中英双向翻译，结果永久缓存 | P1 |
| 统一模型管理 | 平台统一配置API，用户零感知 | P0 |
